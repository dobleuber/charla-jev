Contexto / 05No es una nueva definición de clasificación

Ya teníamos
clasificadores.

El mismo trabajo de fondo

Entra evidencia → sale una etiqueta finita o un puntaje. La precisión, el análisis de errores y la calibración siguen importando.

Flujo de trabajo distinto

Con Jev, defines una pregunta tipada y opciones candidatas en el momento de la solicitud, en lugar de entrenar un clasificador aparte para cada tarea.

Si una regla simple o un clasificador confiable específico para la tarea ya funciona, consérvalo.

Interfaz novedosa, responsabilidades estadísticas conocidas.

{
  "model": "jev-latest",
  "state": {"ticket": {
    "body": "La compra lleva tres días fallando…"}},
  "questions": {
    "category": {"type": "choice",
      "instructions": "¿Categoría de `ticket`?",
      "criteria": {"billing": "Cobros, reembolsos…",
        "technical": "Errores de software…",
        "review": "Poco claro…"}},
    "frustration": {"type": "score",
      "instructions": "¿Frustración en `ticket`?",
      "criteria": ["Tranquilo…", "Frustrado…",
        "Muy enojado…"]},
    "urgency": {"type": "noul",
      "instructions": "¿Atención hoy en `ticket`?"}
  }
}

Polo a tierra / 15Antes de producción

Una respuesta tipada
igual puede estar equivocada.

Evidencia faltante

No le pidas a un modelo que verifique hechos que no están en su entrada.

Diseño de opciones

La redacción, las opciones disponibles y “ninguna” afectan el juicio.

Falsa confianza

Prueba los errores y los umbrales de revisión con casos reservados representativos.

Operación

Planea para caídas, latencia, cambios de modelo, privacidad y una ruta alternativa.

Ninguna cifra de velocidad, costo o precisión que aparece aquí se presenta como resultado medido.

  • Cloudflare Clef y Clef-flash: Apache 2.0; también alojados en Workers AI.

Más control también implica hacerse cargo del cómputo, la evaluación y la adaptación.
